# Computer_Graphics
35 Computer Graphics Micro Mini Projects covering 5 units: line &amp; circle drawing, 2D transformations, clipping, 3D graphics, projections, curves, surfaces, hidden surface removal, illumination and shading. Built with Python, Matplotlib and interactive GUI in Google Colab/Jupyter.
